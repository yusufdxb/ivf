# Pre-registration: revised IVF on an independently authored holdout

Registered 2026-09-26, before any v2 holdout capture. Work lives in `research/failure_corpus/v2/`.

## Status of the data

- The v1 corpus (all 60 cross-backend defects and every other v1 case) is **development
  data**. Its failures were inspected; revised IVF was built against its mechanisms.
- Revised IVF is frozen: `src/ivf` tree `48861c1ea320fe7c8c4bc023653282f401f1fa15`
  (`research/failure_corpus/v2/FROZEN_IVF_V2.txt`), frozen before any v2 development
  evaluation. The v2 harness refuses to run on any other tree.
- The holdout faults were written by an independent author (a separate agent instructed
  not to read IVF, the v2 harness, or any results), from new external sources, and sealed
  unmodified (`FAULTS_SHA256.txt`, commit `b1e09ff`). Disclosure: the author's completion
  summary (family names and mechanisms) was seen before development evaluation. IVF source
  was frozen at that moment and has not changed since.
- New unseen elements: 14 defect families and 4 benign families never used before, seeds
  9 and 10 (never used), and a new platform (Cassie) on which no case of any kind has run.

## Primary question

Does revised IVF materially reduce false acceptance at a comparable false-alarm rate?

- **False acceptance** = defect case not flagged. **False alarm** = clean case flagged
  (Newton clean plus the four benign families). Flag = any verdict other than `PASS`.
- **Comparable false-alarm rate:** IVF FPR minus conventional FPR at most +0.10.
- **Material reduction:** conventional false acceptance minus IVF false acceptance at least
  0.15, with the 95% family-stratified bootstrap CI excluding 0.

## Arms

| Arm | Definition |
|---|---|
| Conventional | Isaac Lab native smoke semantics OR closed-loop performance comparison OR open-loop trajectory RMSE, thresholds 1.25 x worst clean calibration value (unchanged rule; Cassie calibrated on its own clean seeds 0 to 2) |
| IVF (revised) | frozen v2 IVF with the fixed v2 template: v1 oracles and controls plus the seven experiment-input controls, calibrated event allowance; each subject declares `expect_backend` from the plan's requested backend |
| Union | Conventional OR IVF |

## Analysis

- Primary: false-acceptance difference (conventional minus IVF) with McNemar exact test
  and family-stratified bootstrap CI; FPR difference on the 50 clean cases.
- Union: if union false acceptance is lower than **both** arms by at least 0.10 with CIs
  excluding 0, the contribution is reframed as orthogonal experimental-validity checks, not
  as replacing conventional validation.
- Secondary: overlap table (both / IVF only / conventional only / neither) by category;
  localization (attribution top-1 on flagged defects vs majority-category guess); Cassie
  reported separately; per-family table.

## Kill criteria

1. "Revised IVF materially reduces false acceptance" is dead if the reduction is below
   0.15, its CI includes 0, or IVF's FPR exceeds conventional FPR by more than 0.10.
2. "IVF provides orthogonal checks" is dead if union false acceptance is not at least 0.10
   below conventional with a CI excluding 0.
3. "IVF localizes" is dead if attribution top-1 accuracy is below 0.5 on flagged defects.

The holdout is run once. Crashes are recorded as loud failures (every arm flags them).
Negative results are reported with the same prominence as positive ones.
