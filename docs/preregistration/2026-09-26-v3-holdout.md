## Holdout

- Faults written by a new independent author who may not read IVF, any harness, any
  previous holdout's faults or results, or any report. New implementations only (earlier
  mechanisms excluded by list), sealed by hash before capture.
- Benign controls must be demonstrably contract-preserving, with a static config diff per
  platform restricted to visualization/logging/rendering/unused-group paths. A proposed
  benign family whose diff touches anything else is **dropped before sealing**, never
  relabelled after scoring.
- Platforms: GO2, G1, H1, ANYmal-D, Cassie and **Spot** (new robot, never used in any
  earlier round). Seeds 13 and 14 (never used). Cross-backend only: PhysX-trained policy,
  PhysX reference vs Newton/MJWarp candidate. Per (platform, seed): Newton clean plus every
  family.
- Thresholds: 1.25 x worst clean calibration value (seeds 0 to 2, all six platforms),
  frozen and committed before holdout capture. Scored once.

## Primary comparison (three arms)

| Arm | Definition |
|---|---|
| Conventional | native smoke OR closed-loop performance comparison OR open-loop trajectory RMSE |
| IVF | frozen v3 IVF, verdict other than `PASS` |
| Union | Conventional OR IVF |

## Primary claim

> Adding IVF experimental-state/configuration checks to conventional sim-to-sim validation
> reduces silent false acceptance without increasing false alarms.

Decision rule (fixed now):

- **Reproduced** if union false acceptance is lower than conventional false acceptance by
  at least 0.10 with a 95% family-stratified bootstrap CI excluding 0, **and** the union
  adds at most 1 false alarm over conventional on the clean cases (the union can only add
  false alarms, never remove them).
- If reproduced: stop development and prepare the workshop paper.
- If not reproduced: stop and write the negative technical report.

No claim that IVF replaces conventional validation is tested or made.

## Reported (all arms)

Defect recall, false acceptance, false alarms, the both / IVF-only / conventional-only /
neither table, failure categories of unique catches, attribution coverage (flagged
defects with a named cause) and attribution precision (named causes matching the label).
Localization is secondary and does not enter the decision rule. Spot and each platform
are also reported separately.
