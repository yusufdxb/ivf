# IVF v0.1.0-rc1 release notes

The `v0.1.0-rc1` Git release is the first release candidate of IVF 0.1.0rc1, the offline
acceptance and evidence layer for simulator experiments. It checks declared behavioral
contracts and preserves auditable evidence. It does not determine which simulator
backend is physically correct.

## Included in this candidate

- strict `trajectory_bundle/v1` validation with completion markers, normalized task
  configuration, signal metadata, software and hardware provenance, and checksums;
- typed `PASS`, `FAIL`, `INCONCLUSIVE`, `UNSUPPORTED`, `INVALID_EXPERIMENT`, and `ERROR`
  verdicts with stable reason codes;
- sealed evidence bundles with per-file SHA-256 digests and offline verification;
- first-divergence localization by signal, step, affected environment, tolerance, and
  event-level consequence;
- a machine-readable tolerance provenance registry and drift tests for every shipped
  acceptance threshold;
- real PhysX capture through the narrow cart-pole `parity-capture` adapter;
- real Newton/MJWarp capture through the same strict v1 boundary and oracle path;
- an explicit simulator-level reset perturbation modeled after a historical parity-
  harness reset-semantics failure;
- corrected and benign-difference PhysX controls;
- a real PhysX-versus-Newton experiment whose honest typed verdict is `FAIL` because
  trajectory and termination-timing contracts exceeded their budgets, while the final
  survival decision agreement remained `1.0`.

The reset case is not a restored Isaac Lab product defect. The test-only perturbation is
inactive by default, writes zero joint velocity in place of the requested reset velocity,
and is identified in capture metadata.

## Publication provenance

The public Git history removes six obsolete evidence directories whose generated
provenance contained development-workstation paths, one obsolete internal workspace
snapshot, and one internal release checklist. An exact hardware model in the historical
reproduction record is replaced by its coarse public label. The evidence directories
were already absent from the release tree and superseded by the seven current redacted,
sealed bundles. No source code, tolerance, manifest, raw trajectory, oracle output,
verdict, or current evidence seal changed during sanitation.

The exact comparison is recorded in
[`v0.1.0-rc1-equivalence.json`](v0.1.0-rc1-equivalence.json). Historical producer
references inside current sealed evidence remain unchanged and are mapped by identical
Git tree identity in the reproduction record.

## Install and verify

```bash
git clone https://github.com/yusufdxb/ivf.git
cd ivf
git checkout --detach v0.1.0-rc1
uv sync --frozen
uv run ivf doctor
uv run ivf validate validation/examples/synthetic_fixed.yaml
uv run ivf reproduce artifacts/evidence/cartpole-v1-physx-vs-newton-20260810T172728Z-f190cf5b --verify-only
```

Build the release artifacts and verify their package hashes:

```bash
uv build
sha256sum dist/ivf-0.1.0rc1.tar.gz dist/ivf-0.1.0rc1-py3-none-any.whl
```

Verify all seven shipped evidence bundles:

```bash
for bundle in artifacts/evidence/* validation/evidence/*; do
  env -u PYTHONPATH uv run ivf reproduce "$bundle" --verify-only
done
```

The expected flagship verdict is visible without simulator execution:

```bash
uv run ivf report artifacts/evidence/cartpole-v1-physx-vs-newton-20260810T172728Z-f190cf5b --print-verdict
```

## Verified compatibility

- Python 3.12.13 on Ubuntu 22.04.5 LTS for the exact clean RC reproduction;
- Python 3.10, 3.11, and 3.12 are declared and CI-configured; the exact clean local RC
  reproduction used Python 3.12.13;
- Isaac Sim 6.0.0.1 and Isaac Lab 10.2.0 for the recorded real capture workflow;
- Isaac Lab PhysX package 2.8.1;
- Isaac Lab Newton package 1.7.0, Newton 1.4.0.dev0, and the MJWarp solver preset;
- offline reading of shipped legacy parity bundles without importing Isaac Lab.

## Current limits

- Live capture is supported only through the repository's narrow passive cart-pole
  adapter, not through IVF core's general subject runner.
- The real simulator result covers one workload, one recorded Isaac stack, and one
  Newton/MJWarp preset.
- Windows and macOS are untested. The portable evidence integrity boundary is SHA-256,
  not local read-only file modes.
- Cross-machine bit identity is not expected or claimed.
- The flagship comparison leaves binary asset identity, realized backend initial state,
  and backend-internal state explicitly unverifiable.
- A verdict applies only to the declared signals, controls, workload, data, and budgets.
- No verdict establishes physical correctness, universal backend parity, policy transfer,
  or sim-to-real behavior.
